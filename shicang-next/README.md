# 拾藏新版 · 私人放映厅

本目录是视频展示的Next.js新版，Node.js 24.5+、Next App Router、TypeScript、Tailwind、SQLite/Drizzle。版本1.0.1。默认演示馆不需要账号。

## 本目录启动

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:4180/ 。生产模式使用 `npm run build` 后 `npm start`。Windows依赖安装后可双击“启动拾藏新版.cmd”。源代码可直接使用；用户个人环境、原始库、数据库、截图、录屏、开发验证记录和设计参考文档未包含在公开包。

## 数据模式

- 未配置时或 `USE_MOCK=true` 为明确标记的演示馆；15条标题/封面/时长来自公开榜单，其他日期和偏好为模拟。
- 复制 `.env.example` 为自己的 `.env.local`，设 `USE_MOCK=false` 切换真实馆；已有环境文件请编辑，不要覆盖。
- 真实馆运行时可用 `/?demo=1` 打开独立演示馆。两边的观看/笔记/片单状态隔离。
- 所有SQLite库、API缓存和导入快照仅位于 `.local/`，均被Git忽略，不随模板分发。

### AI/旧快照导入

```sh
npm run import:legacy -- /完整路径/我的公开内容.json
```

仅导入你授权读取的公开B站元数据，格式见[AI_IMPORT.md](AI_IMPORT.md)。默认不覆盖已有快照；加 `--replace` 时先备份。程序只保存字段白名单，会丢弃未知账号字段；它不会自动读取浏览器、登录账号或上传数据。重启/刷新后按文件摘要增量导入，保留本地观看状态与笔记。重复BV保留各个公开来源。

`EXCLUDED_FOLDERS`可在本机环境文件中填写额外排除的收藏夹名称（英文逗号分隔），不要把自己的排除策略提交到仓库。私密标记会过滤；AI读取失败、日期未知、原始收藏时间未知时不得猜测。只作为关注来源的停更一年内容会排除，显式收藏仍可浏览。

### 可选账号同步

1. 在你自己的浏览器登录B站，开发者工具网络面板中查看本人发给api.bilibili.com的请求。
2. 将本人Cookie只填写到本机 `.env.local` 的 `BILI_COOKIE=`；不要发给AI、聊天或提交Git。
3. 设 `USE_MOCK=false` 并重启，点“更新内容”。没有Cookie时只更新公开榜单，已有本地快照仍可用。

接口读取本人实际关注名单、近七日动态、公开收藏夹、稍后再看与热门；串行限速至少510ms，关注15分钟、收藏30分钟、榜单1小时缓存。登录过期、验证码与风控需要本人在原站处理。分页上限为关注列表200页、关注动态20页、收藏每夹100页，达到上限会提示，不声称全历史采集。

## 当前规则

- 片单自动组合受预算约束，手动收入与今日拂一件允许超预算。来源多样、优先必看、可放下时保留积尘，热门最多一条；不称为AI评分。
- 积尘按视频发布时间超过90天、在收藏/稍后再看、且本地未看计算。原始收藏时间未知仍保留未知，不用收藏日期替代发布日期。
- 关注浏览近7日更新，有限片数、不无限加载。收藏与稍后再看合并；时下默认前十；自定义收入严格校验BV/完整B站链接。
- 本地隐藏、UP分级、屏蔽分区、观看记录只影响本应用，不修改B站关系。
- 原生播放支持实际进度、自动下一件与小窗续播；官方嵌入只能手动记录时间/下一件。不保证所有视频或所有高清规格可用。
- 藏卷为主题合集和分享长图；拾句为本地笔记；年轮只记录本地数据。

## 代码入口

`lib/rules.ts`为片单/积尘/BV校验，`lib/import-policy.ts`为公开导入过滤，`lib/library.ts`为数据模式和快照合并，`lib/db.ts`延迟初始化SQLite，`lib/bili.ts`为白名单API/缓存/限速，`lib/playback.mjs`保留匿名公开流校验，`components/Shicang.tsx`与`app/globals.css`为界面。Next和Drizzle版本已锁定，升级前重跑测试/构建。

```sh
npm test
npm run typecheck
npm run build
```

完整公开边界与已测项见[仓库验证说明](../TEMPLATE_QA.md)。没有宣称Cookie同步全路径、整单自然播完、真实拖拽全流程或Lighthouse分数通过。
